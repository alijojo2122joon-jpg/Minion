# TelecomShield Mobile

A mobile-first telecom security and billing-integrity auditing foundation.

## Current version

v0.1

### Included

- Android project structure
- Kotlin + Jetpack Compose
- Local network interface discovery
- IPv4 / IPv6 observation
- Interface detection
- Security findings dashboard foundation
- Reports screen foundation

### Planned modules

- Network path analysis
- Evidence engine
- Test sessions
- Billing integrity validation
- Authorized active validation
- Before/after verification
- Evidence hashing
- PDF/JSON reports

## Build

Open the project in Android Studio with JDK 17.

The project is designed for Android 8.0+ and targets Android 15 APIs.

## Important

This project is intended for authorized telecom security testing. It does not implement a generic Internet bypass or free-Internet injector.
